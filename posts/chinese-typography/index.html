中文网页排版，先做好这五件小事

不换字体、不加特效，只调整几个数字，中文页面的可读性就会明显不一样。

中文网页排版常被当成字体问题，其实更多是节奏问题。字与字之间、行与行之间、段与段之间的距离，决定了眼睛能不能顺畅地往下走。

下面五件事，不需要引入任何字体文件，也不需要设计基础。

一、行高给到 1.8 以上#

中文是方块字，字面率高，行与行贴得太近会显得密不透风。正文行高在 1.8 到 2.0 之间比较舒服；英文为主的内容可以稍紧一些。

css
.prose {
  font-size: 1.02rem;
  line-height: 1.95;
}

行高不是越大越好。超过 2.2 之后，行与行的联系会变弱，长文读起来反而累。

二、每行 32 到 40 个字#

行太长，眼睛回扫时容易串行；行太短，节奏被频繁打断。中文正文的舒适区大约在 32 到 40 个字，换算成宽度大约是 36em 到 42em。

css
.prose {
  max-width: 42rem;
}

窗口再宽，正文也不应该跟着无限变宽。留白不是浪费，是给眼睛的休息区。

三、用段间距，而不是首行缩进#

纸质书用首行缩进来区分段落，是因为纸张空间有限。屏幕上空间充足，段间距更清晰，也更适合快速扫读。

css
.prose p {
  margin: 0 0 1.5em;
}

如果一定要保留首行缩进，就别再加段间距，两种方式选一种即可。

四、字重别太细#

很多中文圆体、细体在小字号下会糊成一团，尤其是在没有高分屏的显示器上。正文用 400，强调用 600 左右，标题可以到 600 或 700，但不要用 300 以下的字重来「显得高级」。

系统字体里，PingFang SC、Microsoft YaHei、Noto Sans CJK 都能提供稳定的字重。与其加载一个体积巨大的网络字体，不如把这几个系统字体排好。

五、标点也是排版#

中文标点占一个汉字的位置，英文标点只占半个。混排时最容易出问题的是这几种情况：

  • 中英文之间手动加空格，读起来更松弛：使用 CSS 变量；
  • 省略号用 ……，不要用六个点；
  • 引号用直角引号「」或弯引号“”，不要混用；
  • 破折号用 ——，占两个汉字宽度。

这些细节单看很小，累积起来就是「这个页面很舒服」和「说不上哪里怪」的区别。

最后#

排版没有标准答案。上面这些数字只是起点，真正重要的是：把文章当成给人读的东西，而不是给屏幕填满的东西。
