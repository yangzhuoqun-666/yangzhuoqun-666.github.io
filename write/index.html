写完之后怎么发布？
  1. 点「下载 .md」，或者点「保存到文件夹」并选择项目里的 content/posts/；
  2. 在项目根目录运行 npm run build；
  3. 把新的 dist/ 重新部署到 GitHub Pages 或你的静态托管。

这个页面本身不写服务器，也不上传任何内容；所有操作都在你的浏览器里完成。
